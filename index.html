About

Diagram Editor — a diagrams.net-style editor built with pure HTML5, CSS3, vanilla JavaScript, jQuery and SVG. No frameworks, no diagram libraries.

Drag shapes from the left library, connect them, style them in the right panel, and export to JSON / SVG / PNG. Your work is auto-saved to browser localStorage.

Saves this shape's outline, size and style as a reusable tile in the left library. It stays available in every diagram and is stored in this browser.
